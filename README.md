# 손정윤 키우기 v0.1

HTML, CSS, JavaScript로 만든 16비트 픽셀풍 코믹 육성·방치형 웹게임 프로토타입입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. 별도 설치나 빌드는 필요하지 않습니다.

## 주요 기능

- 현실 1분 = 게임 1시간 및 오프라인 진행
- 확정 취미 6종과 반복 보너스, 지루함 MAX 보상 및 회복
- 일반 취미 진행 중 카톡 행동 병행
- 일기장, 자동 저장, 초기화
- 소개팅 수락·거절과 Step 1 클리어

## 테스트

`node test-game.js`를 실행하면 핵심 게임 규칙 20개를 검증합니다.

진행 데이터는 각 브라우저의 로컬 저장소에 보관됩니다.
